# 1. VISÃO DO PRODUTO

Nome: **Estuda Aí**

Proposta:

> “Você não precisa decidir o que estudar. O Estuda Aí decide seu próximo passo com base no seu desempenho.”

O Estuda Aí será uma plataforma de aprendizagem adaptativa que organiza diferentes objetivos acadêmicos e profissionais do usuário sem misturar conteúdos, cronogramas, matérias ou métricas.

O usuário poderá criar e administrar diferentes **Metas de Estudo**, por exemplo:

* Concurso Público
* Faculdade
* ENEM
* Vestibular
* OAB
* Certificações
* Cursos
* Provas escolares
* Concursos militares
* Outras metas acadêmicas

Cada meta deverá funcionar como um **ambiente de estudo independente**.

Exemplo:

> Meta 1 — Engenharia de Software
> Meta 2 — Concurso Banco do Brasil
> Meta 3 — Inglês

O usuário poderá alternar entre essas metas sem misturar:

* matérias;
* questões;
* progresso;
* revisões;
* cronogramas;
* simulados;
* recomendações;
* estatísticas.

# 3. REGRA FUNDAMENTAL DAS CORES

NÃO utilizar azul, verde, amarelo e laranja igualmente em todas as telas.

A interface deverá possuir uma hierarquia clara.

Prioridade:

**Azul → principal**

**Verde → progresso/sucesso**

**Amarelo → atenção/revisão**

**Laranja → ação/gamificação**

As quatro cores devem parecer parte da mesma identidade visual.

Evitar:

* excesso de cores;
* fundos multicoloridos;
* gradientes exagerados;
* combinações que reduzam contraste;
* aparência infantil;
* estética de aplicativo genérico de IA;
* elementos coloridos apenas por decoração.

Utilizar bastante espaço negativo e superfícies neutras.

# 40. PRINCÍPIO FINAL

A experiência inteira do Estuda Aí deve seguir uma linguagem visual consistente:

**AZUL = foco, navegação e identidade**

**VERDE = progresso, acerto e evolução**

**AMARELO = atenção e revisão**

**LARANJA = ação, desafio e gamificação**

Essas cores devem aparecer de maneira estratégica, elegante e profissional.

O objetivo não é fazer um aplicativo “colorido”.

O objetivo é criar uma **linguagem visual na qual o usuário entende o significado das cores sem precisar pensar**.

Exemplo:

Azul → “isso é parte principal da navegação.”

Verde → “estou evoluindo.”

Amarelo → “preciso prestar atenção nisso.”

Laranja → “isso é uma ação/desafio.”

O design deve continuar excelente mesmo que as cores sejam removidas, portanto a hierarquia visual deverá depender também de:

* tipografia;
* espaçamento;
* tamanho;
* ícones;
* contraste;
* posicionamento;
* componentes.

COMECE analisando o projeto atual, identificando sua estrutura, tecnologias existentes, Design System atual e possíveis problemas arquiteturais antes de implementar a primeira etapa.
