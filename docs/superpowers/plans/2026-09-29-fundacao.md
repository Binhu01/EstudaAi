# Estuda Aí — Plano de implementação da fundação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Entregar a fundação Flutter/NestJS com isolamento testado e shader adaptado à referência fornecida.

**Architecture:** Cliente Flutter independente com Riverpod, GoRouter e Dio. API NestJS modular com identidade Firebase validada no servidor, Prisma/PostgreSQL e entitlement FREE. Shader GLSL nativo, decorativo, com pausa, fallback e movimento reduzido.

**Tech Stack:** Flutter/Dart/Material 3, Node 24/TypeScript/NestJS, PostgreSQL/Prisma, Docker Compose, GitHub Actions.

**Spec:** [Fundação](../specs/2026-09-29-estuda-ai-fundacao-design.md), aprovada em 29/09/2026; adendo visual: shader enviado pelo usuário no mesmo dia.

## Restrições globais

- Trabalhar apenas no repositório EstudaAi, branch `codex/estuda-ai-foundation`.

## Foco de revisão

- Token inválido ou de outro projeto não pode provisionar um usuário (tarefa 1).
- Metas do mesmo usuário continuam isoladas; contexto antigo não pode atualizar uma tela nova (tarefas 2 e 3).
- Tema corrompido no armazenamento local deve recuperar o padrão sem impedir inicialização (tarefa 3).
- Shader deve parar em segundo plano, fora de tela e com movimento reduzido; falha de compilação deve preservar a tela (tarefa 4).
- Texto a 200% e viewport de 360 px não podem ocultar ações ou provocar overflow (tarefa 5).
